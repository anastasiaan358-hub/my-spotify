# Y2K sticker collection

The 50 image files in this directory were curated from Pinterest results connected to the [Y2K sticker ideas page](https://ru.pinterest.com/ideas/%D1%81%D1%82%D0%B8%D0%BA%D0%B5%D1%80%D1%8B-y2k/926301769507/) and its single-icon PNG, star, and heart refinements.

Each image is stored locally as a separate square UI asset so the profile sticker picker does not depend on Pinterest at runtime.
