# Аудиофайлы композиторов XVI века

В эту папку можно положить записи, для которых разрешено копирование и публикация.
Поддерживаются FLAC, M4A, MP3, OGG, WAV, MID и MIDI. Удалённые ссылки скрипт не скачивает.

Скопируйте `catalog.example.csv` в `catalog.csv` и заполните одну строку для каждого
файла. `artist_id` и `work_id` берутся из адреса страницы произведения, например
`/scores/gastoldi/650521`. Поля источника, ссылки и лицензии обязательны.

Импорт выполняется порциями по 25 записей и продолжается с сохранённого места:

```bash
python3 scripts/import_cleared_audio.py
```

Для другой порции укажите `--batch-size 100`; чтобы импортировать все подготовленные
файлы, используйте `--all`. Результат записывается в
`public/classical/catalog/local-audio.json`, а аудио — в `audio/imported/`.
Локальная запись автоматически получает приоритет над встроенным YouTube-плеером.
